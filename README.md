# Ziki Issue OS — Presentation Dashboard & Human-Agent Interaction

Clean, high-density presentation dashboard for Ziki with integrated Human-Agent Interaction (HAI) plan review.

## Features
- **Floating Tablet Shell**: Soft `#edf2f7` framed canvas with `rounded-[32px]` enclosure.
- **Transom-Inspired Aesthetics**: Left sidebar navigation with fast search (`⌘ K`).
- **4 Dot-Matrix KPI Cards**: Real-time arrival and triage metrics with dot-matrix sparklines.
- **Hourly Activity Chart**: Dot-matrix vertical columns showing hourly distribution.
- **Integrated HAI Plan Review Modal**: Human-in-the-loop steering with Git diff viewer, execution constraints, and one-click dispatch (`⌘ + Enter`).

## Deploying to Vercel
This repository is completely static and self-contained with zero database dependencies. Import directly on Vercel for instant deployment.
